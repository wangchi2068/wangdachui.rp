# 战役包设计：《诡秘之主·廷根篇》wangdachui.pi 战役

> 日期：2026-08-07
> 状态：已确认（brainstorming 完成），待实现
> 原则：自玩项目，剧情与角色画像参照《诡秘之主》原著廷根市篇；不锁玩家性格；自动略过日常；按"玩家没看过原著"解释设定。

---

## 一、目标与定位

在现有 wangdachui.pi 上新增一个**可切换战役包**，玩家以克莱恩·莫雷蒂第一视角体验《诡秘之主》廷根市篇（原著第一部的第一章主线），核心体验是"高自由度、选择有后果、多线可换"的叙事——而非数值战斗。

- 现有都市修仙（玄一线）原样保留，作为沙盒测试田
- 战役包 = 一套可切换的 assets（世界书/角色卡/主线/触发规则），零核心代码改动起步
- 服务器启动时用环境变量切换：`WANGDACHUI_CAMPAIGN=lotm`（默认不设 = 都市修仙）

## 二、世界观（向没看过原著的玩家渐进解释）

**核心设定（认知渐进：每幕只解释当前必须懂的）：**

| 概念 | 解释时机 | 一句话说明 |
|---|---|---|
| 非凡世界 | 幕一末尾 | 这个世界表面是维多利亚式工业城市，暗面存在"非凡者"——服食魔药获得超自然能力的人 |
| 序列/魔药 | 幕二（通灵会后） | 非凡体系分 22 条途径，每条途径从序列9（最弱）到序列0（神灵）；服食对应魔药晋升 |
| 占卜家途径 | 幕三（值夜者） | 克莱恩所属途径：神秘、理性、窥探命运；前三级为占卜家→小丑→魔术师 |
| 灰雾 | 幕一开局 | 克莱恩的金手指：可进入灰雾之上的神秘空间，有古堡、能看到远处景象；使用者有污染风险 |
| 罗塞尔日记 | 幕一开局 | 一位已故大人物用汉字写下的日记残页——是克莱恩穿越前的线索，也是与"塔罗会"交易的货币 |

## 五、核心机制（3 个，全部复用现有组件）

### 1. 扮演法（选择后果引擎）
- 每个关键选择判定"是否符合占卜家精神"（谨慎/神秘/理性/窥探命运）
- 符合 → 消化度+（满则获得晋升小丑的资格）；违背 → 污染度+
- 落地：消化度/污染度存账本 plots 分区，跨回合强制兑现

### 2. 灰雾（指引 + 力量 + 成本）
- 兜底指引：玩家连续 2 轮短输入无方向时，灰雾之声主动给方向建议
- 主动求助灰雾 → 污染度小涨、消化度不涨；自己抉择 → 消化度涨
- 防死局：角色死亡 → 灰雾复苏（污染度大幅上升 + 丢失一小段记忆，为"记忆货币"雏形留接口）
- 污染度满 → 不走游戏结束，进入"黑化线"（灰雾主导，剧情方向剧变，仍可玩）

### 3. 关系网（动态因果）
- 账本 relations 分区：信任度/死活/立场
- NPC 只会知道"账本里他该知道的"（情报靠关系网传递，非上帝视角）
- NPC 可死、可走、可被救——每个都有"存活状态"

## 七、世界观解释层（玩家没看过原著的关键设计）

1. **认知渐进**：每幕只解释当前必须懂的概念，绝不一次性灌输
2. **非凡百科面板**（前端侧栏）：已解锁概念才显示，随剧情解锁条目；玩家主动点开看
3. **NPC 说人话**：老尼尔等角色把术语翻译成通俗解释，对话中自然完成教学
4. **罗塞尔日记 = 渐进揭示引擎**：残页按幕解锁，每页揭示一块世界观，翻日记=主动求知奖励

## 十、边界与限制

- 自玩项目：参照原著剧情/角色，不公开分发
- 文案原创化：人物/事件走向照原著，但具体对话、描写、解释为原创（不能照抄书）
- 不引入 cancel（服务器不支持打断生成）
- 数值轻量：不引入 D&D 式属性/技能/装备数值系统（玩家已确认走纯叙事路线）
