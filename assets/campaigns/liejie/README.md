# 战役包：开天辟地之超级裂界

> 原创世界观战役包（非任何现成 IP）。玩家扮演裂隙港的无名拾环人，第一人称。
> 叙述者（旁白）：**潮声**——裂隙港海潮的低语，克制/氛围感/留白，不抢戏。
> 向没看过原著的玩家设计：设定渐进解释，NPC 说人话。

## 怎么切换

```bash
# 本地
WANGDACHUI_CAMPAIGN=liejie npm run web   # 打开 http://127.0.0.1:7620

# 不设置 = 默认诡秘之主（lotm）
npm run web
```

## 文件清单

| 文件 | 用途 |
|---|---|
| `card-liejie.json` | 潮声叙述者卡（内嵌 8 条常驻运行规则 = 三机制契约） |
| `worldbook.json` | 九环/六势力/六区域/三机制设定（向量语义召回，仅 3 条常驻） |
| `arc.json` | 6 幕主线（拾环→立身→追影→险局→真相→离港） |
| `intro.md` | 序章剧本存档（运行时以 first_mes 为准） |

## 三大机制（全账本化，零引擎改动）

| 机制 | 落地 |
|---|---|
| **环影三路**（净化/利用/献祭） | 账本 notes `sys-环影倾向` 行，决策卡选项带 [净]/[利]/[献] 标签，选后 +1（重大 +2）；主导值 ≥3 且领先 ≥2 解锁结局线 |
| **六势力好感** | 账本 relations 六行（level -3~+3），选项门禁 + 检定修正双用途 |
| **轻量 D20 检定** | 卡内契约 + 正文明文【检定】行（LLM 模拟掷骰，失败不判死）；可后续加真随机 check 工具 |

## 玩法提示

- 输入对话/行动/想法，第一人称扮演拾环人
- 斜杠命令：`/state` 看账本（环影倾向/好感存这里）· `/lore 词` 查设定 · `/snap` 存档 · `/back` 回档
- 决策卡出现时选 [净]/[利]/[献]，或输入自己的走向
- 回一个字（如"1"）也能继续——短输入自动推进 + 【你可以…】
