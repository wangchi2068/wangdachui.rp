# 战役包：诡秘之主·廷根篇

> 自玩战役包，剧情与角色画像参照《诡秘之主》原著廷根市篇。玩家扮演克莱恩·莫雷蒂，第一人称。
> 向没看过原著的玩家设计：设定渐进解释，NPC 说人话。

## 怎么切换

服务器启动时设置环境变量：

```bash
# Windows PowerShell
$env:LIYUAN_CAMPAIGN="lotm"; npm run web

# Git Bash
LIYUAN_CAMPAIGN=lotm npm run web

# 不设置 = 默认都市修仙（玄一线）
npm run web
```

## 文件清单

| 文件 | 用途 |
|---|---|
| `card-klein.json` | 克莱恩卡（叙述者视角，玩家=克莱恩，内嵌运行规则） |
| `worldbook.json` | 廷根市/序列/魔药/组织/概念设定（向量检索语义召回） |
| `arc.json` | 6 幕主线（穿越者→通灵会→值夜者→塔罗会→调查→我们拯救了廷根） |
| `intro.md` | 序章剧本（当前已内嵌在卡 first_mes，此文件为剧本存档） |

## 核心机制（叙述者自动执行）

- **扮演法**：谨慎/神秘/理性/窥探命运的选择 → 消化度+；违背 → 污染度+
- **灰雾**：金手指，滥用积累污染；关键选择点可用
- **选择后果**：关系/信任/情报/污染真实变化；偏离原著 OK，大事回归主线
- **渐进解释**：术语通过 NPC 对话自然解释，不灌输

## 玩法提示

- 输入对话/行动/想法，第一人称扮演克莱恩
- 斜杠命令：`/state` 看账本（消化度/污染度存这里）· `/lore 词` 查设定 · `/snap` 存档 · `/back` 回档
- 决策卡出现时在卡片上选，或输入自己的走向
- 想推快节奏就自己给方向；连续短输入时灰雾会主动提示下一步
